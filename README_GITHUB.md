# Бесплатный мониторинг Dota 2 через GitHub Actions

## Что делает бот

Каждые 10 минут GitHub запускает Python-скрипт, проверяет 5 предметов Steam и отправляет найденные объявления с открытым `Chaotic`/`Red` в Telegram. Секреты хранятся только в GitHub Actions Secrets. База уже отправленных `listingid` сохраняется между запусками через Actions cache (кэш не является вечным хранилищем, см. ниже).

## Настройка для новичка (бесплатно)

1. Зарегистрируйся на https://github.com и создай **Public** репозиторий `dota-style-alerts`. НЕ добавляй туда свои токены. Публичный репозиторий нужен для бесплатных стандартных GitHub Actions без помесячного лимита минут.
2. В репозитории нажми **Add file → Upload files**. Загрузи `dota_style_alert.py` и `README_GITHUB.md` из архива. Нажми **Commit changes**.
3. Чтобы добавить workflow, нажми **Add file → Create new file**, в поле имени введи `.github/workflows/dota-monitor.yml`. Открой одноимённый файл из архива на своём компьютере, скопируй его содержимое в редактор GitHub и нажми **Commit changes**. Папка `.github` может быть скрыта в Windows — включи показ скрытых файлов либо открой архив напрямую.
4. В Telegram открой https://t.me/BotFather, выполни `/newbot`, получи токен. Отправь своему новому боту сообщение `/start`.
5. Открой `https://api.telegram.org/botТВОЙ_ТОКЕН/getUpdates` и найди число в `message.chat.id`. Если `result` пуст — отправь боту новое сообщение и обнови страницу. Токен должен остаться приватным.
6. GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Создай два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_CHAT_ID` — число chat.id.
7. Открой **Actions → Dota 2 style alerts → Run workflow**. Отметь `test_telegram` и нажми **Run workflow** — в Telegram должно прийти тестовое сообщение.
8. Затем запусти workflow ещё раз, **без** галочки. Открой логи шага **Check five items**: должны появиться строки `scanned ...`. Теперь автоматические проверки будут идти по расписанию.

## Важные оговорки

- GitHub Actions запускает задачи **по расписанию**, не постоянно. Минимальный интервал 5 минут, в этом наборе установлено 10 минут. GitHub может задерживать и пропускать плановые запуски. В публичном неактивном репозитории расписание отключается после 60 дней без активности — потребуется снова включить workflow или сделать изменение/коммит.
- GitHub Actions cache **может очищаться** (включая при неактивности и из-за лимитов). Если база `dota_alerts.sqlite3` потеряется, ранее найденные лоты могут прийти повторно. Это не абсолютная гарантия дедупликации.
- Скрипт просматривает до `MAX_PAGES=10` страниц на предмет и прекращает просмотр при превышении ценового диапазона. Лоты глубже просмотренного диапазона могут быть пропущены. Steam может блокировать частые запросы.
- Рублёвая цена **примерная**, выводится из Steam `priceoverview` для одного и того же предмета в USD и RUB. Реальную цену и стиль обязательно проверяйте перед покупкой.
- Никогда не добавляйте токены в код, README, коммиты или скриншоты. Токены хранить только в **Secrets**.
- Логи и SQLite-база в публичных действиях могут быть доступны публично через интерфейс Actions/cache; база содержит только ID объявлений.

## Изменить частоту

Открой `.github/workflows/dota-monitor.yml` и измени cron. Например, раз в 20 минут: `3,23,43 * * * *`. При частых проверках Steam может ограничивать запросы.
